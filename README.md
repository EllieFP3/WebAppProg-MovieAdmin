# Movie Review Site Administration Software

## Main Project
The goal of this project is to create a movie review website similar to sites like Rotten Tomatoes.
The site will allow users to create public reviews for movies, which will give the movie an overall rating based on the review average.
Each movie will have details about the movie provided such as runtime, age rating, plot synopsys, and genre.
All site data will be hosted in an api, and delivered through a React front-end.

## Administration Software 
The administrative software for the site will provide users with a way to log in, and manage all of their reviews.
Staff will be able to edit the recorded movie data through the software, which will then be reflected on the front-end.
The code for the admin software is written in Razor and HTML, and uses an ASP.NET Core MVC framework.
